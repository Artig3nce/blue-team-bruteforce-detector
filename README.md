# blue-team-bruteforce-detector

A Python-based brute-force detection tool that analyzes login logs and detects suspicious repeated failed login attempts.

## Features
- Detects failed login attempts
- Tracks attack frequency by IP
- Generates alerts
- Saves alerts to file

## Technologies
- Python
- Regex
- Log Analysis

## Future Improvements
- Real-time monitoring
- Email notifications
- SIEM integration
